Sistema de gestão multiplataforma (desktop + web)

2023 — atual

Projeto freelance que conduzo do início ao fim: levantamento de requisitos com o cliente, arquitetura, implementação, testes, deploy e manutenção. Migrei o sistema de gestão desktop de WinForms para WPF com o padrão MVVM e, depois, para Avalonia UI, permitindo executá-lo em Windows e Linux a partir de uma única base de código. Em seguida desenvolvi o sistema web complementar em ASP.NET Core com Blazor WebAssembly, integrado à aplicação desktop por uma API RESTful. Implementei autenticação e autorização com ASP.NET Identity e comunicação em tempo real com SignalR e WebSockets. A solução está em produção e atende mais de 50 clientes.

  • C#
  • .NET
  • WPF
  • Avalonia UI
  • MVVM
  • ASP.NET Core
  • Blazor WebAssembly
  • Entity Framework Core
  • MySQL
  • SignalR
🔒 Código-fonte privado, por se tratar de um sistema de cliente.
