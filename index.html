Desenvolvedor .NET

📍 Sete Lagoas, Minas Gerais

🏢 Disponibilidade: Belo Horizonte/MG, Joinville/SC e remoto

Sou desenvolvedor .NET com 3 anos de experiência prática em aplicações desktop e web, atuando desde o levantamento de requisitos com o cliente até o deploy e a manutenção evolutiva. Migrei um sistema de gestão legado de WinForms para WPF e, depois, para Avalonia UI, o que permitiu executá-lo em Windows e Linux a partir de uma única base de código. Também desenvolvi o sistema web complementar em Blazor WebAssembly, hoje em produção atendendo mais de 50 clientes.

Atualmente curso Bacharelado em Sistemas de Informação na UNINTER e busco atuar como desenvolvedor .NET júnior em um time estruturado, onde eu possa aprender com pessoas mais experientes e contribuir com o que já construí.
